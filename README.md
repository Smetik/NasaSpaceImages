# NASA Space Images

Android-приложение для поиска, просмотра и сохранения космических изображений из библиотеки NASA.

## Функциональность

- Поиск изображений через NASA Images API.
- Фильтрация по центру NASA и году создания.
- Постраничная загрузка результатов поиска.
- Просмотр подробной информации об изображениях.
- Сохранение изображений в локальный каталог.
- Редактирование названий и добавление комментариев.
- Добавление и удаление изображений из избранного.
- Сортировка сохранённых изображений.
- Удаление изображений из каталога.
- Скачивание оригинальных изображений.

## Технологии

- **Kotlin** — язык разработки.
- **Jetpack Compose, Material 3** — пользовательский интерфейс.
- **Room** — локальная база данных.
- **Retrofit, OkHttp** — сетевые запросы.
- **Kotlin Serialization** — обработка JSON.
- **Coil** — загрузка и отображение изображений.
- **Hilt** — внедрение зависимостей.
- **Coroutines, StateFlow** — асинхронная работа и управление состоянием.
- **JUnit, Compose UI Test** — автоматизированное тестирование.

## Архитектура

Приложение построено с использованием **Clean Architecture** и принципов **SOLID**.

Код разделён на три слоя:

- **Presentation** — Compose-экраны, ViewModel и состояния интерфейса.
- **Domain** — бизнес-модели, UseCase и интерфейсы репозиториев.
- **Data** — работа с NASA API, Room, загрузкой файлов и реализациями репозиториев.

Репозитории разделены по ответственности:

- `SavedImagesRepository` — операции с локальным каталогом.
- `NasaSearchRepository` — поиск изображений NASA.
- `ImageDownloadRepository` — скачивание изображений.

Взаимодействие между слоями осуществляется через абстракции с использованием Dependency Injection.

**Запуск Unit-тестов:**

`./gradlew :app:testDebugUnitTest`

**Запуск UI-тестов (требуется эмулятор или устройство):**

`./gradlew :app:connectedDebugAndroidTest`

## Сборка и запуск

1. Клонировать репозиторий.
2. Открыть проект в Android Studio.
3. Дождаться синхронизации Gradle.
4. Запустить приложение на эмуляторе или Android-устройстве.

## API

Для поиска используется [NASA Image and Video Library API](https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf).

Базовый адрес API: `https://images-api.nasa.gov/`

Для выполнения поисковых запросов API-ключ не требуется.
